## Review and changes

The fetched compatibility commit dynamically resolves the newer console
release API, uses independent close/drain workers on 23H2, preserves final
output after the whole supervised job exits, and waits for canceled I/O
before transferring pipes. It also fixes the JSON duplicate-key diagnostic
use after free. The public Lua API is unchanged; `pty` remains provisional.

The release review found one additional lifetime defect: during shutdown,
an exited legacy console's child state could be freed while an orphaned I/O
packet remained queued. A later Lua finalizer running another process could
pump the loop, which dereferenced the packet's stale completion key before
checking the request's orphan marker.

Fixed by giving overlapped I/O a static completion key. The actual callback
owner stays in `ku_io.src`; job and posted-packet dispatch remain unchanged.
The new native fixture issues and cancels a real pipe read, releases the
source's memory, and dispatches its queued orphaned completion. With the
original dispatcher it exits with `0xC0000005`; with the fix it succeeds.
The fixture is also compiled separately under ASAN. A Lua regression leaves
an exited console open through finalization while another finalizer runs a
process. Independent review found no remaining blocker in the fix.

Updated version constants, identity tests, active documentation, roadmap,
and release status. Added `docs/upgrading-0.8.md`. Historical 23H2 validation
notes and previous release assets remain intact.
