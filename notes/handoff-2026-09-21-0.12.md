## Validation

- Independent Lua and native release reviews found no release blockers.
- The first normal run found one stale test expecting 0.12 to be a future version.
  The version comparison was correct; its test now derives boundary queries from
  the running release. The focused cookbook suite passed all 52 checks.
- The corrected pre-commit gate passed **2,678 normal** checks (93.8 seconds),
  **2,678 ASAN** checks (162.3 seconds), native static analysis, all three
  10,000-case fuzz seeds, and a **26-round / 62-second** soak with zero failures.
- `make publish` repeated the gate on the pushed commit: **2,678 normal** checks
  (112.0 seconds), **2,678 ASAN** checks (213.6 seconds), static analysis and all
  fuzz seeds passed. Its **21-round / 62-second** soak had zero failures, handles
  -3 and private memory +2.4 MB. Signing, verification and publication then passed.
- The downloaded signed executable passed **68** signature, documentation and
  migration-discovery checks, including a copied executable beside stale project
  files with no manifest execution.
- The downloaded executable passed all **11** isolated legacy/migrated exerciser
  commands in 14.07 seconds. The original reference project and cached package
  hashes remained unchanged; owned registry fixtures were cleaned up.

Fresh execution was on **Windows 11 25H2, build 26200.6899, NTFS**, unelevated.
The release retains its Windows 11 23H2 / Windows Server 2025 baseline. Import
inspection found only system DLLs and no static `ReleasePseudoConsole` import;
this is not a fresh 23H2 or Server execution result. The separate reference project
and FlowNet were not modified. No fresh performance benchmark is claimed for this
signed artifact; Step 21 records the earlier development benchmark evidence.

The release ships 57 manual pages. `kuu docs upgrading-from-0.11` describes the
0.11-to-0.12 migration, including history/report changes and continued project
`kuu-eval.md` maintenance. The standalone manual's stale 0.10 introduction was
also brought up to date.
