## The version break, and who has acted on it

0.9.0 is the first three-component version, and it breaks the guard the
manual published through 0.8:

```lua
local major, minor = rt.version:match("^(%d+)%.(%d+)$")
```

`0.9.0` does not match, so a project carrying that guard refuses the runtime
before any task runs. `rt.version_at_least(major [, minor [, patch]])`
replaces it; `docs/upgrading-0.9.md` is the migration.

- **kuu-test-project** was migrated as part of this release, because the
  checklist runs it against the released binary. Its guard now calls
  `rt.version_at_least(0, 7)`, and the smoke check that reads the version
  apart with `re` matches a prefix instead of the whole string, so it holds
  on both shapes. Committed there as `bbf1d7d`; that repository has no
  remote.
- **Time Actual** has **not** been touched. Its `tasks.lua` still carries the
  old pattern at line 6, and its CI still pins an earlier release by hash.
  It will refuse 0.9.0 the moment the executable is copied in. Adopting the
  release there is deliberate work: replace the guard, update the pinned
  hash in `.github/workflows/ci.yml`, run its tasks, and check the CI run.

## What is in the release

From the branch, all of it contract correction rather than capability, which
is the point of a pre-freeze release:

- `Major.Minor.Patch` versions and `rt.version_at_least`.
- `fs.write` retries the rename over its target, bounded at six attempts and
  only for the two errors that mean someone holds the file just now. This
  closes the intermittent `FS access` failure that had left the soak gate
  knowingly unclean since 0.5.
- `fs.dirs` reports a pruned directory in a new `skipped` rather than in
  `paths`, so the obvious walk no longer reads what the prune excluded.
- `json.object`, an ordered object beside `json.array`, for documents
  compared byte for byte.
- `sched.clock` on the performance counter: 1 ms resolution becomes about
  500 ns.
- `svc`, `evt`, and `sys.signature` leave the planned freeze list and join
  `pty` as provisional until a project has driven them.
- The 1.0 criteria gain two amendments: a clean soak gate on every target
  host, and at least one cold adopter.
