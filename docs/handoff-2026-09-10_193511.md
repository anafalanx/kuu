## Direction to preserve

- Kuu is Windows-only, targeting Windows 11 25H2 and later and equivalent
  Windows Server releases.
- Each consuming project carries `kuu.exe` directly in its root and owns its
  `.tools/` directory. Time Actual is independent of the z workspace system.
- Project recipes select pinned upstream tools and use Kuu's HTTP, hashing,
  archives, tasks and process supervision. Do not introduce a built-in Python,
  .NET or PowerShell distribution, shared tool cache, or machine installation.
- Kuu itself is built with its local make/GCC toolchain, not with Kuu tasks.
- Keep reproduced findings in [shortcomings.md](shortcomings.md).
